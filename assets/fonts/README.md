# Locally hosted existing fonts

These files are exact, unmodified WOFF2 downloads referenced by the site's existing official Google Fonts CSS2 request. The family names, font weights, Archivo width range, Unicode ranges and font-display: swap declarations are preserved in ../css/fonts.css. No fallback family or logo/signature drawing was changed.

Families: Archivo (weight 400–800, stretch 62%–125%), Montserrat (600/700), IBM Plex Mono (400/500), IBM Plex Sans (400/500/600). All subsets returned by the CSS are retained, including Latin and Latin Extended for Turkish. Browsers download only the subsets matching rendered characters.

Source stylesheet: https://fonts.googleapis.com/css2?family=Archivo:wdth,wght@62..125,400..800&family=Montserrat:wght@600;700&family=IBM+Plex+Mono:wght@400;500&family=IBM+Plex+Sans:wght@400;500;600&display=swap

Font files: 24 unique files; 643976 bytes. CSS @font-face declarations: 41.

- Montserrat: OFL-montserrat.txt — https://raw.githubusercontent.com/google/fonts/main/ofl/montserrat/OFL.txt
